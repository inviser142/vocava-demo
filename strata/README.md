# STRATA — architectural 3D loop study

An original demonstration of an architectural macro loop on a fictional premium real-estate platform sign-in screen. STRATA is a placeholder identity. This is a concept, not an operating service or a completed client commission.

The form has no backend and does not submit or store credentials.

- `index.html` — responsive sign-in screen with the loop as background.
- `loop.html` — standalone playback and downloadable video files.
- Original procedural Blender geometry; EEVEE ray tracing and fast GI for this demonstration.
- 1920×1080, 30 fps, six seconds, no audio.
- WebM VP9, H.264 viewing copy, HEVC fallback and lightweight JPG poster.
- Reduced-motion preference respected; background can be paused manually.

All included visual assets are original work. No external models, textures, music, fonts, trackers or third-party scripts.
